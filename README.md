# موقع صالح الدخيل · Saleh Al Dakheel

موقع شخصي بلغتين (العربي هو الأساس ومن اليمين لليسار، والإنجليزي بزر واحد بكل صفحة والموقع بيتذكّر اختيار الزائر) لصالح الدخيل، مدير مشاريع في مكتب إدارة المشاريع المؤسسي (EPMO) بوزارة الموارد البشرية والتنمية الاجتماعية بالرياض.
كل معلومة بالموقع مصدرها `brief.md` (بروفايله على لينكدإن، بوستاته، وملف الـ PDF تبعه). ما في ولا رقم أو اسم مخترع.

**الحالة:** معاينة لسا ما وافق عليها صالح. كل الصفحات فيها `noindex` (محركات البحث ما بتأرشفها).

## الفكرة: «نقطة آخر السطر»
ملف الـ PDF تبعه نفسه صار موقع: أوراق نيلي غامق وأوف وايت، عناوين عريضة بتنتهي بنقطة (متل "Experience." بملفه)، وأرقام صفحات صغيرة بالزاوية 001، 002…
- كل عنوان بينتهي بنقطة بتنزل وبتنط شوي وبتطلع منها موجة، لأنو صالح بيسكّر الشي اللي بيملكه للآخر (قيمة Ownership)، وشعاره ثلاث جمل بثلاث نقاط: "Always learning. Always building. Always aiming higher."
- الأقسام أوراق بتركب فوق بعض وإنت نازل، متل صفحات ملفه.
- بالرئيسية لوحة زجاج فيها برنامج سخاء بالنقاط: 18 نقطة مليانة (المشاريع اللي بيقودها) و82 دائرة (اللي بيشرف على تمكينها).
- الفكرة المفاجئة: مسيرته معروضة كمخطط جانت (Gantt) متل أي مشروع: أشرطة للوظائف والدراسة، ونقاط للشهادات، وخط «اليوم».
- الألوان من ملفه: نيلي `#3D3B8E` وأوف وايت `#F1F1F3`. الخطوط: Kufam للعناوين العربية، Alexandria للنص العربي، Outfit للإنجليزي. كلهن جوّا الموقع (ما في Google Fonts).

## وين بتعدّل
- **كل النصوص:** `content.py`. كل نص زوج `T("عربي", "English")`.
  - `[[18]]` يعني رقم بيعد من الصفر لما يبين (و`[[40+]]` بيحافظ على الـ +).
  - النقطة بآخر أي عنوان بتصير النقطة المتحركة لحالها.
  - الكلمات الإنجليزية والأرقام جوّا النص العربي بتنلف بـ `dir="ltr"` أوتوماتيك (مشان 2018–2024 ما تنقلب).
- **CONFIG** بأول `content.py`:
  | المفتاح | شو بيعمل |
  |---|---|
  | `BASE_URL` | رابط الموقع الحي. منه بينبنى الـ canonical والـ hreflang والـ sitemap وصورة المشاركة |
  | `PREVIEW` | `True` = `noindex` بكل الصفحات |
  | `PHOTO` | صورته (مربعة، 800px أو أكبر) جوّا `src/assets/img/`. فاضي = بيطلع حرف «ص.» بداله |
  | `EMAIL` | بريده (موجود بملفه العام) |
  | `PHONE` و`WHATSAPP` | فاضيين عن قصد لحد ما يوافق. أي قيمة بتحطها بتطلع لحالها بالفوتر وصفحة التواصل |
  | `LINKEDIN` | رابط حسابه |
  | `MAKER` | رابط موقعك بالفوتر |
  | `DOMAIN` | الدومين الخاص (بيكتب ملف `CNAME`) |
- **الشكل:** `src/assets/style.css` (الألوان والمسافات متغيرات بأول الملف). **الحركة والسلوك:** `src/assets/site.js`.
- **صورة المشاركة والأيقونات:** `python3 tools/make_images.py` (بتنكتب بـ `src/assets/img`).

```bash
python3 build.py      # بيطلع الموقع جاهز بمجلد docs/
```

## بعد ما يوافق صالح (شيل الـ noindex)
1. بـ `content.py` خلي `"PREVIEW": False`.
2. `python3 build.py` وارفع.
3. هيك بيختفي `<meta name="robots" content="noindex">` من كل الصفحات. `robots.txt` و`sitemap.xml` و`llms.txt` و`llms-full.txt` موجودين من هلأ.
4. انتبه: `robots.txt` ما بيقرأه أي بوت إلا إذا كان بجذر الدومين. على `nouraldeentofi.github.io/saleh-al-dakheel/` ما إله تأثير، بيشتغل لما يصير عنده دومين خاص.

## النشر على GitHub Pages
- كل الروابط والملفات نسبية، فالموقع بيشتغل تحت أي مسار متل `/saleh-al-dakheel/`.
- الموقع المبني بمجلد `docs/` بنفس الريبو (`saleh-al-dakheel`)، والنشر من Settings ← Pages ← Deploy from branch ← `main` / `docs` (متل موقع حمد وأيمن).
- `docs/.nojekyll` موجود مشان GitHub ما يلعب بالملفات.
- `BASE_URL` = `https://nouraldeentofi.github.io/saleh-al-dakheel/`.

**دومين خاص (مثلًا `salehaldakheel.com`):**
1. `DOMAIN` = الدومين، و`BASE_URL` = `https://الدومين/`، وابنِ.
2. بإعدادات الدومين: `CNAME` لـ `www` على `nouraldeentofi.github.io`، و4 سجلات `A`: `185.199.108.153` و`185.199.109.153` و`185.199.110.153` و`185.199.111.153`.
3. بالريبو: Settings ← Pages ← Custom domain، وفعّل Enforce HTTPS.

## الذكاء الاصطناعي ومحركات البحث
- كل المحتوى مكتوب جوّا الـ HTML (البوتات ما بتشغّل JavaScript).
- JSON-LD بكل صفحة: Person (كل كتابات اسمه بالعربي والإنجليزي، المسميات بمرادفاتها، الشهادات، الجامعة، الوزارة، اللغات، لينكدإن)، ProfilePage، BreadcrumbList، وFAQPage بصفحة التواصل مطابقة للأسئلة الظاهرة.
- `llms.txt` و`llms-full.txt` (فيه كل نص الموقع باللغتين)، `robots.txt` بيرحّب بـ GPTBot وClaudeBot وPerplexityBot وGoogle-Extended وغيرهم، `sitemap.xml` مع hreflang، canonical، وصورة مشاركة `og.png`.
